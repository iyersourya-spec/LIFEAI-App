# LIFEAI

LIFEAI is an Android-first everyday AI hub.

## Features

- AI Assistant
- Study Center
- Stories
- Local Discovery
- Daily Tools
- Courses
- Travel
- Creative Tools
- Profile
- Free Fire redeem-code information

## Build

Open the project in Android Studio.

Allow Gradle to sync.

Run the app on an Android device or emulator.

## Important

The AI assistant, maps, database, authentication, live information and audio
streaming need backend/API integration.

Never put private API keys directly inside the Android source code.
